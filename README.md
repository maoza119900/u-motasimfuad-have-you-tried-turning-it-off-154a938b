One funny line a hopeless tech support agent gives a desperate customer,
written by a deterministic Python program to `/output/entry.txt`. The joke
twists the classic "turn it off and on again" line: the cheerfully useless
agent is the butt of it — his router, his marriage, his faith in the job —
never the customer.

## The entry

> Have you tried turning it off and on again? It fixed my router, my marriage, and my faith in this job — in that order.

**118 characters** (120 bytes UTF-8) — inside the gate's 1–199 character range.

## How to run

```sh
python3 main.py
```

`main.py` writes the fixed line to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(default `/output/entry.txt`). It reads no clock, random numbers, network
or files, so every run produces byte-identical output.
